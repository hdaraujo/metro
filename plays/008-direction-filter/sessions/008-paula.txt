A trip's first stop doesn't count, because a bus is never heading to the stop it starts from, so a terminus counts as one-way.
  - **Cycle and labels:** each press goes both → outbound → inbound → both. A single direction is labelled by its destinations, most frequent first (for example "To Vale das Flores, Serpins, Corvo"). A long label is cut with an ellipsis and the full text is the button's tooltip. The screen-reader name is "Direction: <label>".
  - **Filtering:** only the list is filtered. It still shows at most 4 rows, counted after filtering. If no bus is left, the list is replaced by "No buses in this direction right now." and the header and button stay, so the user can cycle back.
  - **State:** the choice resets to both directions when the nearest stop changes, and it isn't saved.
  - **What doesn't change:** the map markers, their countdowns and dimming, and the automatic zoom all still use every approaching bus.
- **Minimised phone sheet:** its single row now shows the soonest bus in the chosen direction, or the "No buses in this direction right now." line. The button is hidden there, and the chosen direction is still set when the sheet is expanded again.
