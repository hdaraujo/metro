  ⎿ 1	Metro is a mobile-first installable web app (React PWA using MapLibre GL JS on OpenStreetMap tiles) for riders of the Coimbra Metrobus in Portugal. It opens straight onto a map showing where you are, your nearest Metrobus stop and, eventually, where the buses are, so a rider can glance at a phone and decide when to leave. The main user is the owner, a regular rider using it one-handed on a phone before heading out, and any other rider uses it anonymously with nothing to set up. There is no existing frontend, so this sets the visual language from scratch. It should feel calm, glanceable and utilitarian: the map fills the screen and everything else is minimal floating chrome with large touch targets near the bottom for thumb reach. Use a clean system sans-serif stack, a light, muted map base, and a restrained palette where colour is reserved for meaning. Use the official Metrobus line colours for lines S1, S2, U1, U2 and U3 (to be taken from the route data), one accent colour for the user's location dot and accuracy halo, and a distinct highlighted marker for the nearest stop. Any bus data carries a small but clearly visible "scheduled" badge because it is estimated from the timetable and must never look live. OpenStreetMap attribution is always visible in a map corner. Design the phone frames at 390 by 844, plus one desktop frame of the map screen to show that it scales responsively. The first screen is the Map home screen: a full-screen map centred on the user's blue location dot and zoomed so that the nearest stop (and the nearest bus, if one is shown) is in view. The nearest stop is highlighted with its name and the lines that serve it in a compact bottom card. It has a recentre/locate button and the OSM attribution. The second screen is the Locating state shown while the app waits for a location fix or for the browser's permission prompt: the map over Coimbra with a subtle "Finding your location…" indicator. The third screen is the Location unavailable state, shown when permission is denied or location fails: the map shows a default view over Coimbra, with a short, non-blocking message explaining that the nearest stop needs location access and a button to try again. Save the canvas payload as `plays/001-project-structure/design/canvas.html`.
